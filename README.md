Entry for the [Make the AI Judge Laugh](https://make.fun/bounty/u-tstore-make-the-ai-judge-laugh-2d7571ae) bounty on [make.fun](https://make.fun/): a program that writes one funny line (at most 200 characters) to `/output/entry.txt`, to be read cold by a house AI judge.

## Run

```sh
node main.ts
```

It writes the entry line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The line

> My fitness tracker congratulated me on 10,000 steps — every one paced around the kitchen at 2 a.m., hunting snacks I hid from myself and forgot, so I outsmarted myself twice and still got a medal.

196 characters, one line, written to land cold: a concrete midnight scene, a turn the reader does not see coming, and a second twist that still amuses on a re-read.
